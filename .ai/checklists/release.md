# Release Checklist

リリース可能なプロジェクトになった後に使用します。

- [ ] 対象範囲、version、変更内容、既知の制約が合意されている。
- [ ] `TESTING.md`で要求されるFull Validationが成功している。
- [ ] security、data migration、互換性への影響を確認した。
- [ ] 設定と秘密情報が対象環境で安全に準備されている。
- [ ] deploy、rollback、backup/recovery、監視の手順と担当が確認されている。
- [ ] 利用者・運用者向け文書と必要な告知が更新されている。
- [ ] リリース後の確認方法と中止判断を定義した。
