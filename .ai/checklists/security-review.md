# Security Review Checklist

- [ ] 資産、主体、信頼境界、想定する脅威を確認した。
- [ ] 認証と認可を境界で強制し、最小権限になっている。
- [ ] 外部入力を検証し、出力先に応じて安全に扱っている。
- [ ] 秘密情報と機微データを最小化し、保存・転送・削除方針を満たす。
- [ ] log、error、telemetryに機微情報を漏らさない。
- [ ] 外部サービスと依存関係の権限、データ共有、供給網リスクを確認した。
- [ ] 失敗時の既定動作、rate limit、濫用、復旧を検討した。
- [ ] 未解決リスク、例外、必要なfollow-upと承認を記録した。
