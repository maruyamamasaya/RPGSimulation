# 0002: iOSネイティブ版へ移行し、ゲーム仕様から開発する

## Status

Accepted — 2026-10-01

今後の開発方針について[0001](0001-static-es-modules.md)を置き換える。旧参照実装の構造として0001は保持する。

## Context

Web版のUI課題への対応負担が大きいため、ユーザーはWeb版の開発を終了し、ゲームロジックを文書化してiOSアプリへ移行する方針を選んだ。

## Decision

Swift・SwiftUIのネイティブアプリとして進める。旧Webコードとテストは参照用に保持する。まずルール・数式・処理順・定義データを整理し、未決定の仕様を合意した後、UIから独立したSwiftエンジンを検証し、最小画面へ接続する。

初回機能範囲、最低OS、保存方式、旧データ移行、配布方法は別途決める。既存公開サイトの停止操作はこの判断の記録だけでは実施しない。

## Alternatives

Web UIの改修継続は、UI課題の負担を踏まえて採用しない。旧コードの削除は、移行時の参照を残すというユーザーの選択に従い行わない。

## Consequences

ゲームルールを画面制約から切り離して再検討できる。一方、Swiftへの再実装とiOSでの検証が必要になる。旧JavaScriptの乱数・丸め・保存との完全互換は自動的に保証されず、必要性を決めて検証する。
